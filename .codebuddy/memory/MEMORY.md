# MEMORY（dsh-auto-pass）

## 项目事实源
- **`AGENTS.md`（仓库根）是本项目的活文档、也是唯一权威事实源**：改代码后必须同步它。
  本目录只记跨会话的偏好与「怎么干活」的约定，不复制 AGENTS.md 的内容。

## 用户偏好 / 工作方式
- 一切 review（代码、方案、自查）**必须对抗性**：默认「这次改动有问题」，主动构造反例；
  每个疑点必须有下落（查实排除给依据，或指出风险要求修）；结论分「发现的问题（按严重度）」+「已确认无问题的方面」。
- 分析问题从**本质与硬约束**出发推导，不用「别人都这么写」作理由；现状 ≠ 改动依据。
- **没有 90% 把握必须停下来问**，且必须用 `ask_followup_question` 给 2–4 个选项，禁止纯文本询问。
- 能调专用工具就别写脚本（读/写/搜/改一律用工具，不用 cat/sed/Get-Content 等替代）。
- 每个源文件头要有 `@description` / `@author` / `@date`，改动追加 `@modify`；函数必须注释；
  复杂逻辑要有中文行内注释；禁止空代码块；单行语句也必须带 `{}`。
- 交接文案统一写到工作区根的 `.handoff/`（不存在则先建），不要放 `doc/` 等位置。
